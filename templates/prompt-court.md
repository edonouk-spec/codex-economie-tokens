# Modèle de demande compacte

```
Objectif : <une phrase>
Fichiers : <chemins précis>
Contraintes : changement minimal, pas de nouvelle dépendance
Terminé quand : <test ou comportement attendu>
```

Exemple :

```
Objectif : corriger le calcul du total TTC
Fichiers : src/cart/total.py
Contraintes : changement minimal
Terminé quand : pytest tests/test_total.py passe
```
